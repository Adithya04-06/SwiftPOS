# Components

This document outlines the reusable components found in the SwiftPOS design system. When importing into Figma, these should be converted to native Figma Components.

## 1. Sidebar
- **Variants:** Expanded (Default), Collapsed (Future Scope)
- **Elements:** Logo, Navigation Links (Active/Inactive), User Profile

## 2. Topbar
- **Elements:** Page Title, Search/Filter (optional), Notifications, Action Buttons

## 3. Buttons
- **Variants:**
  - Primary (Blue background, White text)
  - Secondary (White background, Outline, Primary text)
  - Danger (Red background, White text)
  - Text (No background, Primary/Secondary text)
- **States:** Default, Hover, Disabled

## 4. Cards
- **Variants:**
  - KPI Card (Title, Value, Optional trend/icon)
  - Product Card (Image/Placeholder, Title, Category, Price, Add Button)
  - Standard Container Card (Padding, White background, Shadow, Border)

## 5. Tables & Rows
- **Elements:** Table Header, Table Row (Default), Table Row (Hover)
- **Variants:** With Status Badge, With Action Buttons

## 6. Inputs & Forms
- **Variants:**
  - Text Input (Default, Focused, Error)
  - Search Bar (With search icon)
  - Select/Dropdown

## 7. Status Badges
- **Variants:**
  - Success (Green background, Dark Green text - In Stock, Paid)
  - Warning (Yellow background, Dark Yellow text - Low Stock)
  - Danger (Red background, Dark Red text - Out of Stock)

## 8. POS Specific Components
- **Cart Item:** Product name, price, quantity controls (+, -), total price, remove icon.
- **Payment Method Card:** Cash, Card, UPI (Icon, Title, Selection state).

## 9. Receipt
- **Elements:** Store Header, Transaction Details, Item List, Totals, Footer.
